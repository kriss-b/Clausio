# Marque Clausio

Icône « Tuile C » — un C blanc dans une tuile bleue, avec un point rouge à l'ouverture
(clin d'œil à « Clausio propose »). Style aligné sur La Suite numérique de l'État.

## Couleurs
- Bleu France : `#000091`
- Rouge Marianne : `#E1000F`
- Blanc : `#FFFFFF`

## Fichiers
- `clausio-tuile.svg` — logo principal (tuile arrondie, fond transparent autour).
- `clausio-tuile-pleine.svg` — tuile pleine bord à bord (favicon, PNG, tuiles d'app).
- `clausio-tuile-monochrome.svg` — une seule couleur (`currentColor`) pour contextes N&B.
- `clausio-mark.svg` — la marque seule (C + point), sans tuile, pour fonds clairs.
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon-180.png`, `icon-512.png` — icônes web.

## Usage
Laisser une marge de protection autour du logo (≈ 1/8 de sa hauteur). Ne pas déformer,
recolorer hors palette, ni ajouter d'ombre/dégradé.
